# API-тесты для Stellar Burgers

## Описание проекта

Этот проект содержит автоматизированные API-тесты для сервиса [Stellar Burgers](https://stellarburgers.nomoreparties.site/), используя документацию API, предоставленную для тестирования.

## Состав

В проекте используются следующие библиотеки:

*   **Python 3.11+**
*   **PyTest** - фреймворк для запуска и организации тестов.
*   **requests** - библиотека для отправки HTTP-запросов к API.
*   **allure-pytest** - плагин Allure для интеграции с PyTest и создания наглядных отчетов о тестах.
*   **Faker** - библиотека для генерации фейковых данных для тестовых сценариев.


## Покрытие тестами

Автотестами покрыты следующие сценарии сервиса Stellar Burgers:

**Регистрация пользователя:**

*   [x] Успешная регистрация уникального пользователя.
*   [x] Попытка регистрации уже существующего пользователя.
*   [x] Регистрация пользователя с пропуском обязательного поля.

**Авторизация пользователя:**

*   [x] Успешная авторизация существующего пользователя.
*   [x] Неуспешная авторизация с неверным логином.
*   [x] Неуспешная авторизация с неверным паролем.

**Изменение данных пользователя:**

*   [x] Успешное изменение данных пользователя (email, имя, пароль) авторизованным пользователем.
*   [x] Попытка изменения данных пользователя без авторизации.
*   [x] Попытка изменения email на уже используемый другим пользователем.

**Создание заказа:**

*   [x] Создание заказа с авторизацией пользователя.
*   [x] Попытка создания заказа без авторизации пользователя.
*   [x] Создание заказа с ингредиентами.
*   [x] Попытка создания заказа без ингредиентов.
*   [x] Попытка создания заказа с неверным хешем ингредиентов.

**Получение заказов пользователя:**

*   [x] Получение заказов авторизованного пользователя.
*   [x] Попытка получения заказов неавторизованным пользователем.
